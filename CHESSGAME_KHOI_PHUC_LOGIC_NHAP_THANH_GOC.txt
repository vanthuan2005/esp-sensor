XOA TOAN BO DOAN TREN.

Sau khi xoa, filterLegalMoves() chi nen loc:
- 2 = nuoc di thuong
- 3 = nuoc an quan

Vi du phan cot loi nen la:

------------------------------------------------
    private int[][] filterLegalMoves(
            int oldRow,
            int oldCol,
            int[][] moves) {

        for (int row = 0; row < SIDE; row++) {
            for (int col = 0; col < SIDE; col++) {

                if (moves[row][col] == 2 ||
                        moves[row][col] == 3) {

                    if (!isLegalMove(
                            oldRow,
                            oldCol,
                            row,
                            col)) {

                        moves[row][col] = 0;
                    }
                }
            }
        }

        return moves;
    }
------------------------------------------------

KHONG xu ly 4/5 trong ham nay nua.
